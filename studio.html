📄 GPT로 전자책 만드는 법

아래 순서만 그대로 따라 하면 됩니다. 처음이면 5분 정도 걸려요. (ChatGPT 화면이 영어라도 버튼 이름만 그대로 찾으면 돼요.)
1

OpenAI 사이트 열기

인터넷 주소창에 platform.openai.com 을 입력하거나, 아래 버튼을 누르세요. (PC·스마트폰 모두 됩니다)

🔗 platform.openai.com 열기
2

로그인 또는 회원가입

화면이 뜨면 “Continue with Google”(구글로 계속하기)을 누르는 게 제일 쉬워요 — ChatGPT 쓰던 계정 그대로 됩니다.
구글이 없거나 이메일로 하려면 “Sign up”(가입) → 이메일·비밀번호 입력 → 받은 인증 메일의 확인 버튼을 누르면 끝. 이미 계정이 있으면 “Log in”.

로그인 / 가입 화면 예시
3

결제수단 등록 (이걸 안 하면 키가 안 돌아가요)

API는 ChatGPT 유료(Plus)와 별개예요. 쓴 만큼만 과금되니, 먼저 카드 등록 + 소액($5~10) 충전을 해두면 바로 작동합니다.
왼쪽 메뉴 Settings → Billing → Add payment details 순서.

🔗 결제(Billing) 열기
OpenAI 결제 화면 예시
4

API 키 만들기

API keys 페이지에서 “Create new secret key”를 누르고, 이름(예: moneycrew)을 적은 뒤 Create를 누르세요.

🔗 API keys 열기
OpenAI API keys 화면 예시 — 우측 상단 초록 버튼
5

키 복사 — 딱 한 번만 보여요!

⚠ 생성되면 sk-... 로 시작하는 키를 바로 복사하세요. 이 창을 닫으면 다시 볼 수 없어요. 메모장에 잠깐 붙여두면 안전합니다. (잃어버리면 새로 만들면 됩니다.)

키 발급 직후 화면 예시 — Copy 버튼
6

이 프로그램에 붙여넣기

이 프로그램 상단 [AI 연결] → “ChatGPT (OpenAI)” 선택 → 모델 gpt-4o → 방금 복사한 키 붙여넣기 → [저장하고 연결].

지금 AI 연결하기 →
이 프로그램의 [AI 연결] 화면 — ChatGPT 선택 후 키 붙여넣기
7

전자책 만들기

주제·타깃을 적고 [AI로 전자책 만들기]를 누르면, 몇 분 뒤 전자책이 완성돼요. [완성된 전자책 보기]에서 인쇄·PDF·다운로드로 저장하면 끝!

💰 비용은 얼마나 드나요? 쓴 만큼만 과금돼요. gpt-4o 기준 전자책 1권에 대략 수백 원~수천 원 수준(챕터 수·모델에 따라 다름). 더 저렴하게는 gpt-4o-mini, 더 고품질은 gpt-4.1을 고르면 됩니다.
🛠 안 될 때 · “키가 올바르지 않아요 / 401” → 키를 다시 복사해 붙여넣기(앞뒤 공백 주의)
· “사용량 한도 / insufficient_quota” → 2번 Billing에서 결제수단·크레딧 확인
· 생성이 느려요 → 정상이에요(챕터를 하나씩 씁니다). 빠르게는 gpt-4o-mini
